# 스크랩 모니터링 대시보드

공장 관리자가 스크랩 적재 상태와 운영 정보를 확인하는 브라우저 대시보드의 프론트엔드
Repository다. 현재 소스는 브라우저 실행, Continuous Integration (CI)과 Release 흐름을
확인하는 최소 화면을 제공한다.

## 문서

| 문서 | 내용 |
| --- | --- |
| [`docs/project-spec.md`](docs/project-spec.md) | 프로젝트 목적, 범위와 외부 경계 |
| [`docs/design-reference.md`](docs/design-reference.md) | 미확정된 구체적 설계 참고안 |
| [`docs/implementation.md`](docs/implementation.md) | 현재 구현 기술, 실행과 검증 방법 |

## 소스 이용 조건

> 이 Repository는 코드 검토와 참고를 위해 Public으로 제공하며 프로젝트 소스 코드에 별도 라이선스를 부여하지 않는다.
