# 스크랩 모니터링 대시보드

공장 관리자가 브라우저에서 스크랩 적재 상태와 수거 판단에 필요한 정보를 확인하는 React 기반 대시보드 클라이언트 저장소다.

## 시작 문서

작업자는 루트 `AGENTS.md`를 먼저 읽고, 해당 지침에 명시된 순서로 `docs/project-spec.md`와 나머지 프로젝트 문서를 읽는다. 제품 범위와 완료 기준은 `docs/project-spec.md`를 따른다.

## 현재 상태

저장소 지침과 프로젝트 문서만 초기화된 상태다. React 애플리케이션, 패키지 메타데이터, 의존성, 테스트와 Continuous Integration (CI)는 아직 구현되지 않았다. 상세한 현재 상태와 다음 단계는 `docs/status.md`에서 관리한다.

## 이용 조건

이 저장소는 코드 검토와 참고를 위해 공개한다. 별도의 라이선스를 부여하지 않으며, 법률상 허용된 범위를 제외하고 코드를 사용, 복제, 수정, 배포하거나 파생 저작물을 작성할 권한을 부여하지 않는다. 외부 의존성은 각 제공자의 라이선스를 따른다.
