## 상위 컨텍스트

스크랩 모니터링 시스템은 LiDAR 2대, 고정 USB 웹캠, 라즈베리파이 엣지 장비, 모니터링 서버와 관리자 브라우저로 구성한다. 엣지 장비는 LiDAR 데이터를 변환하고 높이를 산출하며 카메라 영상을 서버로 전달한다. 모니터링 서버는 상태 데이터, 이력, 알림, 실시간 영상과 녹화 영상을 관리자 브라우저에 제공한다.

이 저장소는 관리자 브라우저에서 실행되는 대시보드 클라이언트를 구현한다. 센서 원본 데이터 처리, 높이 산출, 서버 영속화와 미디어 서버 구현은 다른 개발 저장소의 책임이다.

LiDAR 2대는 적재 공간의 서로 다른 측정선에서 높이를 산출한다. 두 측정 결과를 결합하는
방식과 대표 높이 및 대표 적재율의 측정 의미는 외부 계약을 따른다. 프론트엔드는 서버가
제공한 결과를 사용하며 측정 의미를 임의로 결정하지 않는다.

프론트엔드는 실제 서비스에 synthetic 입력을 연결해 데이터와 영상 사용자 흐름을 검증한다.
실제 장비의 입출력, 현장 calibration과 측정 로직의 정확도 검증은 프론트엔드 구현 범위에
포함하지 않는다.

## 목적

공장 관리자가 브라우저에서 스크랩 적재 상태를 확인하고 수거 판단에 필요한 정보를 사용할 수 있는 대시보드를 제공한다.

## 사용자 기능

대시보드는 다음 사용자 목적을 지원한다.

| 기능 | 목적 |
| --- | --- |
| 현재 모니터링 | 서버가 제공하는 측정 및 적재 정보, 장비 상태, 알림과 실시간 영상 확인 |
| 변화 및 운영 이력 | 시간에 따른 적재 변화와 수거, 알림 및 오류 이력 확인 |
| 녹화 영상 | 조회 가능한 녹화 구간 검색과 재생 |
| 관리 기능 | 수거 임계율과 프로젝트에서 확정한 운영 설정 관리 |

기존 화면의 정보 구조, 카드 순서와 배치를 유지한다. 현황 화면은 현재 상태, 실시간 영상,
측정 영역, 최근 24시간 적재율, LiDAR 1, LiDAR 2, 활성 알림과 장비 상태의 8개 카드로 구성한다.
Backend 제공 범위에 맞추어 카드를 제거하거나 별도 화면 구조로 대체하지 않는다.
추가 정보 때문에 기본 화면의 카드 크기, 표의 열 너비와 행 높이를 변경하지 않는다.
이벤트 상세와 녹화 범위는 기존 표시 선택 시 겹쳐지는 상세창으로 제공한다.
현황 화면은 장비 진단과 pit 이름을 표시하지 않는다.

현황, 이력과 녹화 화면의 우측 상단은 Backend와 대시보드 사이의 데이터 수신 상태와
마지막 수신 시각을 표시한다. 적재율 판단 가능 여부와 장비 상태는 각 정보 영역에서
구분한다.

현재 상태 카드의 적재율 경보는 Backend의 현재 경보 평가 결과를 표시한다. 프론트엔드는
임계율로 등급을 다시 계산하거나 경보 등급을 실제 작업의 대기, 적재 중 또는 수거 중으로
변환하지 않는다. 현재 계약에는 실제 수거 진행 상태가 없으며 수거 관련 판단 사건과 실제
완료 기록을 진행 중 상태로 사용하지 않는다.

현재 상태 카드의 1시간 전 적재율은 Backend에 저장된 과거 관측값을 표시한다. 브라우저의
장기 보관 상태나 현재 적재율에서 역산하지 않으며 수거에 따른 보정을 하지 않는다.
현재 측정 상태와 과거 관측의 유효성은 구분한다. 최근 수거 후 경과는 Backend가 제공하는
최근 수거 종료 시각을 기준으로 한다. 평균 수거 주기는 Backend가 자동 수거 종료 감지 사이의
간격으로 집계한 값을 표시하며 Frontend에서 집계하지 않는다.

프론트엔드는 서버 응답의 단위, 시각과 상태 의미를 확인한 뒤 기존 화면의 데이터 모델로
변환한다. 제공되지 않은 값은 해당 영역에서 미지원 또는 정보 없음으로 구분한다. 화면에
배치한 참고도는 실제 측정 배치와 구분한다. 높이 산출, 적재율 판정과 예측 로직은 구현하지
않는다. 화면 구조 또는 지표 의미의 변경은 외부 계약 동기화와 분리한 제품 결정으로 관리한다.

## 산출물

- 관리자용 웹 대시보드
- 현재 모니터링, 이력, 영상 조회와 관리 기능의 사용자 흐름
- 상태 데이터, 이력, 알림, 실시간 영상과 녹화 영상의 연동 경계
- 실제 연동 전 화면과 사용자 흐름을 검증할 개발 환경

## 범위

### 포함 범위

- 현재 모니터링, 이력, 녹화 영상과 관리 기능
- 조회 및 관리 기능의 접근 제어 흐름
- 실시간 상태, 이력, 알림과 영상 연동
- 로딩, 데이터 없음, 연결 끊김과 오류 상태 표시
- 관리자용 브라우저 환경 대응

### 제외 범위

- LiDAR Software Development Kit (SDK) 연동과 높이 산출
- 카메라 영상 수집, 인코딩과 미디어 서버 구현
- 백엔드 API, 영속 데이터베이스와 서버 저장소 구현
- 실제 현장 데이터 수집과 측정 로직 검증
- 모바일 애플리케이션 구현

## 외부 계약

브라우저 대시보드는 다음 연동 범위를 사용한다.

| 경계 | 용도 |
| --- | --- |
| 대시보드 제공 | 브라우저에서 대시보드 실행 |
| 상태 및 이력 데이터 | 현재 상태, 이력, 임계값과 관리자 요청 및 응답 |
| 실시간 상태 갱신 | 상태와 알림의 변경 내용 수신 |
| 실시간 영상 | 현재 현장 영상 수신 |
| 녹화 영상 | 녹화 구간 조회와 영상 재생 |

정확한 제공 위치, 통신 방식, 주소, 데이터 형식과 오류 형식은 백엔드 및 카메라 역할과
협의하여 확정한다.

## 데이터 계약 경계

프론트엔드는 측정 및 적재 정보, 변화 이력, 운영 이력, 알림, 영상 정보와 관리 설정을
외부 서비스에서 받는다. 데이터 개체와 필드, 단위, 시간 기준, 상태 분류, 측정선별 결과와
통합 결과의 관계는 측정 및 서버 역할과의 계약에서 확정한다. 이 명세는 해당 구조를 먼저
고정하지 않는다.

현재 상태 조회는 단일 pit의 v2 계약을 따른다. 제공되지 않은 측정값이나 기능을 v1 또는
synthetic data로 보충하지 않는다. 이력과 관리 기능은 v2 관측 및 판단과 별도로 표시한다.
실제 서비스의 제공 범위는 `docs/contracts/backend/README.md`를 따른다.

운영 pit 및 camera 식별자는 이미지와 분리한 same-origin runtime JSON 설정으로 제공한다.
프론트엔드는 설정을 검증한 뒤 해당 대상의 데이터와 영상을 요청하며 설정 누락 및 오류를
build 기본 식별자로 대체하지 않는다. 설정 변경은 다음 전체 페이지 로드에 적용한다.

## 접근 제어

현재 v2 및 녹화 조회에는 Backend session과 조회 권한을 적용하고 관리 기능에는 관리자
권한을 적용한다. 계정 제공, 장기 운영 session과 요청 보호는 Backend 계약 및 운영 환경을
따른다. 프론트엔드는 자격 증명을 소스 코드나 공개 설정에 포함하지 않는다.

## 녹화 영상 조회

프론트엔드는 미디어 서비스가 제공하는 녹화 영상을 조회하고 재생한다. 검색 조건, 제공
메타데이터, 운영 사건과 영상의 연결, 조회 가능 범위와 재생 방식은 미디어 및 서버 역할과의
계약에서 확정한다. 현재 제품 범위는 조회, 재생, 다운로드와 관리자의 날짜 녹화 삭제이며
수동 녹화 생성과 보관 정책 변경 화면은 포함하지 않는다. 날짜 녹화 삭제는 같은 날짜 영상을
사용하는 이벤트 구간의 재생도 불가능하게 하므로 삭제 전에 관리자에게 이를 확인받는다.

날짜 녹화와 이벤트 녹화를 구분하고 날짜 녹화를 경보나 수거 사건으로 표시하지 않는다.
날짜 녹화는 실제 확보 구간과 누락 구간을 구분해 재생하며 하루 전체가 녹화되었다고
가정하지 않는다. MP4 다운로드는 준비 가능한 지난 날짜에만 제공한다. 조회 결과가 없거나
실패해도 조회 조건, 녹화 목록, 영상, 녹화 정보와 녹화 파일의 기본 카드 배치를 유지한다.

## 초기 개발과 검증

공개 가능한 synthetic data와 시험 영상으로 화면 구성과 사용자 흐름을 확인한다. 이
데이터는 프론트엔드 동작 확인을 위한 것이며 측정 로직의 시뮬레이션 검증에는 사용하지 않는다.

실제 서비스의 계약은 [계약 안내](contracts/README.md), 실행 검증은
[검증 기준](testing.md)을 따른다.

## 실행 제약

- 관리자용 브라우저에서 실행
- 일반 인터넷에 직접 공개하지 않는 네트워크 접근 제어
- 공장 내부망, Virtual Private Network (VPN) 또는 이에 준하는 허용된 네트워크에서 조회 화면 접근
- 관리 기능과 설정 변경에 인증 및 권한 확인 적용
- 자격 증명, 사설 주소, 현장 사진, 운영 데이터와 외부 제공 원본의 저장소 포함 금지

## 기술과 검증 경계

채택한 기술과 화면 동작은 [구현 정보](implementation.md), 실행 환경은
[개발 환경](development.md), 기능별 회귀 및 실제 서비스 검증은 [검증 기준](testing.md)을
따른다. 미제공 데이터와 외부 미구현은 [계약 매핑](contracts/backend/frontend-mapping.md)에
기록하며 제품 범위를 해당 서비스의 현재 제공 범위로 축소하지 않는다.
