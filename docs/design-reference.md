# 프론트엔드 설계 참고안

## 문서 역할

이 문서는 제품 명세를 변경하지 않고 화면 초안을 검토하기 위한 설계 참고안을 제공한다.
제품 요구사항과 데이터 의미는 `docs/project-spec.md`, 채택한 기술과 내부 설계는
`docs/implementation.md`, 개발 순서와 완료 조건은
`docs/development-workflow.md`에서 관리한다.

참고안은 구현 요구사항이나 완료 조건이 아니다. 현재 Issue에서 적용할 항목을 선택하고
인수 조건으로 승인한 뒤 구현한다. 현재 작업 요청, 제품 명세와 확인된 외부 계약이 이
문서보다 우선한다.

## 적용 기준

구현 작업자는 참고안을 사용하기 전에 다음 4개 기준을 적용한다.

1. 제품 명세와 현재 Issue의 완료 조건 확인
2. 미확정 사항의 결정 주체와 확인 시점 식별
3. 브라우저 렌더링을 통한 배치와 상호작용 검토
4. 채택한 결과의 코드와 구현 문서 반영

## 남은 설계 대상

현재 설계가 필요한 항목은 6개다.

| 항목 | 설계 대상 | 필요한 입력 |
| --- | --- | --- |
| 화면 계층 | 경로, 내비게이션과 화면 간 이동 | 조회 접근 정책과 주요 사용자 흐름 |
| 현황 배치 | 정보 우선순위, 카드 크기, 영상과 그래프 비율 | 브라우저 렌더링 피드백 |
| 이력 탐색 | 기간 선택, 사건 필터와 상세 이동 | 조회 가능 기간과 서버 검색 계약 |
| 녹화 영상 | 검색, 재생과 녹화 영상 다운로드 배치 | 녹화 메타데이터와 재생 및 다운로드 계약 |
| 관리자 화면 | 임계율, 알림 대상과 알림 정책 관리 | 관리 항목, 알림 전송, 인증과 권한 계약 |
| 공통 표현 | 색상, 글꼴, 간격, 상태 표현과 접근성 | 구현된 화면과 사용자 검토 |

## 화면 계층 참고안

상위 화면을 현황, 이력, 녹화 영상과 관리자의 4개 영역으로 구분할 수 있다. 정확한 경로와
접근 정책은 사용자 흐름과 인증 계약을 확인한 뒤 채택한다.

| 화면 | 경로 예시 | 남은 설계 |
| --- | --- | --- |
| 현황 | `/` | 기본 진입 경로와 내비게이션 노출 |
| 이력 | `/history` | 조회 조건 유지와 현황 복귀 |
| 녹화 영상 | `/recordings` | 검색 결과, 재생과 다운로드 이동 |
| 관리자 | `/admin` | 인증 진입과 권한 오류 처리 |

공통 화면은 내비게이션 영역과 콘텐츠 영역으로 구분할 수 있다. 좌측 내비게이션의 사용
여부와 너비, 콘텐츠 카드의 열 수와 순서는 기본 및 확장 뷰포트의 브라우저 렌더링을
검토하며 결정한다.

## 공통 표현 참고안

인증 후 화면은 짙은 배경의 상단 바를 공통으로 사용한다. 상단 바는 브랜드, 4개 상위 메뉴,
알림 진입과 관리자 메뉴로 구성한다. 로그인 화면은 같은 브랜드 상단 바를 사용하고 상위
메뉴, 알림 진입과 관리자 메뉴를 노출하지 않는다.

화면 목업은 Noto Sans KR 글꼴을 사용한다. 글자 위계는 다음 5개로 구분한다.

| 계층 | 크기와 굵기 | 대상 |
| --- | --- | --- |
| 페이지 제목 | 36px, 굵게 | 화면 이름 |
| 섹션 제목 | 22px, 600 | 세로 악센트가 있는 제목 |
| 내부 제목 | 18px, 600 | 카드 및 섹션 내부 제목 |
| 본문 | 16px, 보통 | 설명과 데이터 |
| 라벨 | 15px, 600 | 입력 및 표 머리글 |

페이지 제목은 진한 네이비 `#172238`을 사용하고 별도의 색상 장식을 적용하지 않는다.
주황색은 활성 메뉴, 섹션 악센트, 주요 버튼과 그래프에 사용한다. 로그인 제목은 중앙 정렬을
유지하고 주황색 자물쇠 아이콘으로 테마를 연결한다.
섹션 제목의 주황색 악센트바는 너비 5px, 높이 20px와 모서리 반경 2px를 사용한다.
악센트바와 제목의 간격은 6px이다. 제목의 줄 높이는 22px로 고정하고 악센트바를 수직
중앙에서 1px 아래로 보정한다. 활성 메뉴의 가로 하단선은 상단 내비게이션에서만 사용한다.

기본 1584 x 992 목업에서 현황, 이력, 녹화 영상과 관리자 화면의 마지막 카드 하단은
뷰포트 아래쪽에서 36px 떨어진 위치에 맞춘다.

모든 화면의 공통 하단 영역은 왼쪽에 카피라이트 문구, 오른쪽에 애플리케이션 버전을
표시한다. 실제 버전은 빌드 과정에서 주입하는 값을 사용한다. 목업의 `Version 0.1.0`은
표시 예시다.

운영 상태는 의미 색상을 적용한 텍스트만 표시한다. 상태 앞에 색상점, 원형 체크 또는
캡슐형 배지를 배치하지 않는다. 그래프의 데이터 점, 사건 마커와 입력 컨트롤의 원형 표시는
운영 상태 표현에 포함하지 않는다.

이벤트 유형은 어두운 평문으로 표시한다. 이력의 이벤트 내용은 어두운 평문과 작은 색상점을
함께 사용한다. 수거 완료는 초록색, 수거 필요와 임계 도달을 포함한 알림은 브랜드 주황색
`#F58A07`, 오류 내용은 빨간색 색상점을 사용한다.
이벤트 내용에 배경과 테두리를 사용하지 않는다.

## 현황 배치 참고안

현황 화면은 관리자의 수거 판단과 이상 상태 확인에 필요한 정보가 먼저 보이도록 구성한다.
화면 초안은 다음 7개 정보 그룹을 사용한다.

| 정보 그룹 | 내용 |
| --- | --- |
| 적재 요약 | 대표 적재율, 수거 임계율, 적재 상태와 수거 임계 도달 예상 시각 |
| 위치별 측정 | Light Detection and Ranging (LiDAR) 장비 2대의 높이, 현재 표면 프로파일, 상태와 마지막 측정 시각 |
| 단기 변화 | 최근 24시간 대표 적재율 그래프 |
| 실시간 영상 | 현장 영상과 영상 상태 |
| 활성 알림 | 해결되지 않았거나 조치가 필요한 알림 |
| 장비 상태 | LiDAR 2대, 카메라와 엣지 장비의 상태 |
| 데이터 연결 | 브라우저가 관찰한 상태 데이터 연결 상태 |

다음 배치 관계를 브라우저 초안에서 검토한다.

- 적재 요약과 위치별 측정의 시각적 우선순위
- `LiDAR 1`과 `LiDAR 2`의 위치 구분
- 실시간 영상과 위치별 표면 프로파일의 화면 비율
- 실시간 영상 아래에 배치하는 `LiDAR 1`과 `LiDAR 2` 표면 프로파일의 가독성
- 활성 알림, 장비 상태와 상단 데이터 연결 상태의 노출 순서
- 정상 상태 정보와 조치가 필요한 상태의 대비

제품 명세나 확인된 외부 계약이 같은 항목을 정의하면 해당 내용을 사용한다. 아래의 의미,
상태와 표시 형식은 화면 초안을 위한 후보이며 제품 계약을 변경하지 않는다.

### 측정과 적재 표시 참고안

화면 초안은 위치별 높이 2개와 서버가 제공하는 대표 적재율 1개를 사용한다.

| 항목 | 초안의 의미 | 표시 참고안 |
| --- | --- | --- |
| `LiDAR 1` 높이 | 첫 번째 측정 위치의 바닥부터 스크랩 표면까지 높이 | 미터 단위 소수점 첫째 자리 |
| `LiDAR 2` 높이 | 두 번째 측정 위치의 바닥부터 스크랩 표면까지 높이 | 미터 단위 소수점 첫째 자리 |
| 대표 적재율 | 서버가 유효한 위치별 결과를 통합한 공간 전체의 현재 적재율 | 0부터 100까지의 정수 퍼센트 |
| 수거 임계율 | 관리 설정에 저장된 수거 판단 기준 | 0부터 100까지의 정수 퍼센트 |
| 수거 임계 도달 예상 시각 | 서버가 임계율과 변화 데이터를 사용해 계산한 예상 시각 | 예측 결과와 예측 기준 시각 |

대표 적재율과 수거 임계율은 서버 값을 정수로 반올림해 표시할 수 있다. 보수적인 초안은
두 LiDAR 측정이 모두 정상일 때만 대표 적재율을 현재 값으로 표시한다. 서버가 예측 결과를
제공하지 않으면 수거 임계 도달 예상 시각을 `예측 불가`로 표시한다.

마지막 측정 시각은 현재 값의 최신성을 판단하는 보조 정보로 사용한다. `LiDAR 1`과
`LiDAR 2` 이름은 유지하며 화면 배치와 측정선 설명으로 위치를 구분한다.

각 LiDAR의 현재 표면 프로파일은 같은 측정 시각에 해당 센서의 측정선을 따라 얻은 공간별
표면 높이를 표현한다. 시간에 따른 변화, 측정선 전체의 평균 높이 또는 두 LiDAR를 통합한
결과로 표현하지 않는다. 가로축의 원점과 진행 방향, 세로축의 값과 단위, 유효하지 않은
측정점의 표현은 측정 및 서버 계약에서 확정한다.

`LiDAR 1`은 청색, `LiDAR 2`는 청록색으로 구분한다. 두 측정선은 서로 다른 공간 단면이며
각 그래프의 방향과 위치 표시는 서버가 제공하는 공개 가능한 측정선 정의를 기준으로 한다.

### 실시간 영상과 위치별 프로파일 배치 참고안

실시간 영상은 스크랩 적재 상태를 식별할 수 있는 시점을 사용한다. 정확한 카메라 설치 좌표와
화각은 현장 설치 결과와 미디어 계약에서 확정한다. 현재 엣지 장비의 기본 캡처 설정은
`640 x 480` 해상도와 4:3 종횡비다. 이전에 검증한 고해상도 모드는 `1920 x 1080`
해상도와 16:9 종횡비다.

화면의 실시간 영상 경계는 기본 캡처 설정에 맞춘 4:3 종횡비를 유지한다. 브라우저는 영상
요소를 경계 안에 비율을 유지한 채 맞추고 영상을 늘이거나 자르지 않는다. 4:3 영상은 경계를
채우고 16:9 영상은 위아래 여백을 사용한다. 여백은 영상 영역과 구분되지 않는 어두운 색으로
표현한다. 전체 화면 재생도 같은 방식으로 원본 종횡비를 유지한다.

현황 화면은 12열 그리드를 사용하고 현재 상태, 측정 데이터와 운영 상태의 3개 카드 행으로
구분한다. 행 이름은 화면에 별도 제목으로 노출하지 않고 8개 카드가 같은 섹션 제목 위계를
사용한다. 각 행의 배치 참고안은 다음과 같다.

| 행 | 왼쪽 | 가운데 | 오른쪽 |
| --- | --- | --- | --- |
| 현재 상태 | 적재 요약 4열 | 실시간 영상 4열 | 2.5D 측정 영역 4열 |
| 측정 데이터 | 최근 24시간 대표 적재율 4열 | `LiDAR 1` 현재 표면 프로파일 4열 | `LiDAR 2` 현재 표면 프로파일 4열 |
| 운영 상태 | 활성 알림 4열 | 장비 상태 8열 | 장비 상태 카드의 연속 영역 |

실시간 영상 아래에는 `LiDAR 1` 현재 표면 프로파일을 배치하고 그 오른쪽에는 `LiDAR 2`
현재 표면 프로파일을 배치한다. 같은 행의 카드 높이, 제목 기준선, 내부 여백과 아래쪽 경계를
맞춘다. 대표 적재율의 최근 24시간 그래프는 위치별 공간 프로파일과 같은 행에 배치하되 시간
변화 그래프라는 의미가 구분되도록 제목과 축을 표시한다.

2.5D 측정 영역은 적재 공간, 스크랩 표면과 두 LiDAR 측정선의 관계를 단순화한 입체 개형으로
표시한다. 정확한 현장 치수와 설치 위치는 표시하지 않는다. 각 LiDAR와 표면 측정선 사이에는
청색과 청록색의 22% 불투명도 측정 평면을 표시하고 표면과 만나는 2개의 측정선을 같은 색으로
강조한다. 이 영역은 공간 관계를 설명하며 높이 통계는 중복 표시하지 않는다. 각 LiDAR의
평균, 최소와 최대 높이는 해당 표면 프로파일 카드에 표시하고 평균을 가장 크게 표현한다.

### 상태 표현 참고안

화면 초안에서 구분할 상태 분류는 4개다.

| 분류 | 상태 참고안 | 판단 주체 |
| --- | --- | --- |
| 적재 상태 | `정상`, `수거 필요`, `수거 진행`, `판정 불가` | 서버 |
| 장비 상태 | `정상`, `장애`, `상태 확인 불가` | 서버 |
| 데이터 연결 상태 | `연결 중`, `연결됨`, `재연결 중`, `연결 끊김` | 브라우저 |
| 실시간 영상 상태 | `연결 중`, `실시간 영상`, `영상 연결 불가` | 브라우저와 미디어 서비스 |

한 LiDAR만 정상인 화면 상태에서는 정상인 위치의 높이만 현재 값으로 표시하고 다른 위치와
대표 결과를 `측정 불가` 또는 `판정 불가`로 표현할 수 있다. 두 LiDAR가 모두 비정상이면
높이와 대표 결과를 현재 값으로 표시하지 않는다. 마지막 정상 값이 필요하면 현재 값과
구분되는 보조 정보로만 제공한다.

브라우저는 연결과 마지막 수신 상태를 근거로 데이터 연결 상태를 정하고 현장 장비의 장애
원인을 추정하지 않는다. 영상이 중단되면 정지된 마지막 프레임을 실시간 영상으로 표시하지
않고 영상 상태와 마지막 정상 수신 시각을 표시한다.

### 단기 변화와 알림 참고안

단기 변화 그래프는 최근 24시간의 대표 적재율을 실제 측정 시각에 따라 표시한다. 세로축은
0부터 100 퍼센트를 사용한다. 측정 주기를 고정값으로 가정하지 않고 서버가 제공한 결측
구간을 임의로 연결하지 않는다.

대표 적재율 추세선은 주황색을 사용한다. 수거 임계율은 추세선 및 사건 색상과 구분되는 낮은
투명도의 청회색 점선과 청회색 평문으로 표시한다.

활성 알림은 해결되지 않았거나 조치가 필요한 항목만 표시한다. 후보 유형은 수거 임계 도달,
측정 오류, 장비 장애, 데이터 연결 문제와 외부 알림 전송 실패다. 알림의 생성, 분류와 해결
상태는 서버 계약을 따른다.

## 이력 화면 참고안

이력 화면은 조회 조건, 적재율 이력과 이벤트 이력의 3개 구역으로 구분할 수 있다. 조회
조건의 기간과 이벤트 유형은 아래 두 이력 구역에 함께 적용한다. 적재율 이력은 대표 적재율
그래프와 사건 마커를 제공하고 이벤트 이력은 조회 조건에 해당하는 전체 사건 목록, 건수와
페이지 이동을 제공한다.

장기간 변화 그래프는 대표 적재율을 사용하고 위치별 LiDAR 높이의 순간값이나 평균값은
그래프로 집계하지 않는다. 기간 선택의 기본값, 확대 단위와 사건 마커 표시는 서버 조회
계약과 실제 데이터 밀도를 확인하며 결정한다.

사건 이름은 그래프 상단의 같은 높이에 배치하고 각 이름과 실제 발생 지점을 청회색 점선으로
연결한다. 발생 지점은 사건 의미에 맞는 작은 색상점으로 표시한다.

현재 상태에서 같은 시각의 이력 또는 녹화 영상으로 이동할 수 있다. 이동할 때 유지할 기간과
선택 항목은 화면 간 사용자 흐름에서 확정한다.

## 녹화 영상 화면 참고안

녹화 영상 화면은 서버가 제공하는 녹화 구간을 기간으로 검색하고 재생한다. 검색 결과에
녹화 식별자, 시작 및 종료 시각, 생성 사유와 재생 가능 여부를 사용할 수 있다. 실제 필드는
미디어 계약을 따른다.

영상 재생과 선택한 녹화 영상의 다운로드를 한 상세 화면에 배치할 수 있다. 다운로드 대상은
선택한 녹화 영상 1개다. 파일 형식, 파일명, 코덱, 해상도와 용량은 미디어 및 서버 계약을
따른다. 연속 재생, 사건 관련 구간 구분, 재생 실패 복구와 다운로드 실패 표현은 미디어 및
서버 계약을 확인한 뒤 결정한다.

녹화 목록, 영상 재생, 녹화 정보와 다운로드 카드는 같은 본문 하단선에 맞춘다. 녹화 정보
카드는 남는 높이를 사용하고 다운로드 카드는 하단에 고정해 상세 영역을 하나의 열로
구성한다.

## 관리자 화면 참고안

관리자 화면은 수거 임계율, 알림 대상 관리, 알림 정책과 테스트 알림의 4개 독립 구역으로
구분할 수 있다. 수거 임계율 입력에는 현재 값, 서버가 제공하는 허용 범위, 입력 오류, 변경
확인, 저장 결과와 동시 변경 충돌을 표현할 수 있다.

관리자 화면의 두 행은 본문 높이를 채우고 각 행의 카드 하단선을 맞춘다. 알림 정책의 저장
동작과 테스트 알림의 실행 동작은 각 카드 하단에 배치해 독립된 기능임을 구분한다.

알림 대상에는 이름, 이메일, 전화번호, 수신 채널과 활성 상태를 사용할 수 있다. 전화번호는
문자 수신 대상으로 표현한다. 등록, 수정, 중지, 주소 및 번호 검증과 중복 처리 방식은 서버
계약을 따른다. 화면 예시에는 실제 개인정보를 사용하지 않는다.

알림 정책에는 수거 필요, 측정 오류와 장비 장애의 발송 여부, 발송 시점, 반복 알림과
오류/장애 복구 알림을 사용할 수 있다. 오류/장애 복구 알림은 측정 오류 또는 장비 장애가
정상으로 돌아온 경우에만 적용한다.

알림 정책은 최대 반복 횟수를 설정할 수 있다. 서버는 최대 횟수에 도달하거나 해당 이벤트가
해제되면 반복 발송을 종료한다.

테스트 알림은 알림 정책 저장과 분리된 즉시 실행 기능이다. 등록된 알림 대상과 하나 이상의
수신 채널을 체크박스로 선택하고 고정 문구 "스크랩 모니터링 테스트 알림입니다. 이 메시지를
받았다면 알림 수신 설정이 정상입니다."를 발송한다. 브라우저는 테스트 발송을 서버에
요청하고 서버는 알림 전송 서비스와 연동한다. 화면은 알림 전송 서비스가 요청을 접수한
경우에만 발송 요청 성공을 표시한다. 실제 배달 완료는 알림 전송 서비스가 배달 결과를
제공하는 경우에만 구분한다. 지원 채널, 반복 간격, 전송 실패 처리와 정책 적용 범위는 서버
및 알림 전송 계약을 따른다.

관리자 작업 이력의 제공 여부와 필드는 인증 및 서버 계약에서 확정한다.

## 외부 연동 참고안

외부 역할과 협의할 미확정 통신 방식의 예시는 4개다. 실제 프로토콜과 주소는 서버 및 미디어
계약에 맞게 채택한다.

| 경계 | 통신 방식 예시 | 용도 |
| --- | --- | --- |
| 대시보드 제공 | Hypertext Transfer Protocol (HTTP) 정적 파일 | Hypertext Markup Language (HTML), JavaScript와 Cascading Style Sheets (CSS) 로드 |
| 상태 및 이력 데이터 | HTTP JavaScript Object Notation (JSON) | 현재 상태, 이력, 임계율과 알림 설정 요청 및 응답 |
| 실시간 상태 갱신 | WebSocket | 상태와 알림의 변경 내용 수신 |
| 녹화 영상과 파일 | HTTP 미디어 및 다운로드 | 녹화 구간 조회, 재생과 녹화 영상 다운로드 |

연동 설계 전에는 데이터 개체, 시간대, 오류 형식, 실시간 메시지의 순서와 중복, 재연결 후
동기화, 인증 오류, 미디어 주소 만료와 재시도 조건을 확인한다. 외부 연동부를 화면 구성과
분리하는 내부 구조는 채택한 뒤 구현 문서에 기록한다.

## 인증 참고안

조회와 관리 기능의 인증 범위, 계정 제공 방식, 세션 또는 토큰 사용과 요청 보호 방식은
백엔드 및 운영 환경에서 결정한다. 서버 측 세션을 채택하면 `HttpOnly` 쿠키와
Cross-Site Request Forgery (CSRF) 방어를 함께 검토한다.

관리자 인증 상태 없이 관리자 화면에 접근하면 로그인 화면으로 이동할 수 있다. 로그인
화면은 브랜드 헤더, 아이디, 비밀번호와 로그인 동작만 제공하고 인증 전 내비게이션과 운영
정보를 노출하지 않는다. 로그인에 성공하면 사용자가 접근하려던 관리자 화면으로 이동한다.

로그인, 로그아웃, 권한 없음과 세션 만료 뒤 이동은 확정된 접근 정책에 맞춰 사용자 흐름과
브라우저 상태로 구현한다.
