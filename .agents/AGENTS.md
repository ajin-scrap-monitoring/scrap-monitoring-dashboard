# 저장소 작업 지침

이 문서는 저장소 작업 지침의 단일 정본이다. 루트 `AGENTS.md`는 이 파일을 가리키는 심링크로 유지한다.

## 필수 읽기 순서

1. `.agents/AGENTS.md`
2. `docs/project-spec.md`
3. `docs/implementation.md`
4. `docs/status.md`
5. `docs/git-workflow.md`
6. `README.md`

`docs/project-spec.md`는 제품 범위와 구현 계약의 정본이다. 명시적인 요청 없이 수정하지 않는다. 나머지 문서와 코드는 프로젝트 명세와 충돌하지 않게 유지한다.

## 작업 경계

- 관리자 브라우저 대시보드 클라이언트와 이를 위한 개발, 테스트 및 배포 설정
- 서버 데이터, 실시간 상태, 실시간 영상과 녹화 영상의 클라이언트 연동 경계
- 센서 원본 데이터 처리, 높이 산출, 영상 수집, 서버 영속화와 미디어 서버 구현 제외
- 서버가 제공한 판정 결과 표시 및 프론트엔드의 적재율, 수거 상태와 오류 상태 재계산 금지
- 명세에 확정되지 않은 외부 계약을 임의로 고정하지 않고 교체 가능한 경계로 분리

## 문서 역할

| 문서 | 역할 |
| --- | --- |
| `docs/project-spec.md` | 제품 목적, 범위, 외부 계약과 완료 기준의 읽기 전용 정본 |
| `docs/implementation.md` | 현재 채택한 내부 구조와 구현 상태 |
| `docs/status.md` | 검증된 현재 상태, 결정 필요 사항과 다음 단계 |
| `docs/git-workflow.md` | 브랜치, Pull Request, 검사와 병합 원칙 |
| `README.md` | 저장소 진입점과 이용 조건 |

문서는 현재 반영된 상태만 설명한다. 같은 사실은 한 문서를 정본으로 두고 다른 문서에서 중복하지 않는다.

## 검증 원칙

- 변경 전후 `git status` 및 `git diff` 확인
- 문서 링크, 심링크, 저장소 경계와 민감 정보 포함 여부 검증
- 소스 코드 작업 시 변경 범위에 해당하는 ESLint, TypeScript, 테스트와 배포용 빌드 실행
- 의존성이 없는 상태에서 의존성 기반 검사를 실행한 것으로 기록하지 않음
- 실행하지 못한 검사와 외부 설정 제약을 `docs/status.md`에 기록

## 보안 규칙

- 자격 증명, 세션 식별자, 토큰, 비밀키와 환경 설정값 저장 금지
- 실제 사설 주소, 상위 로컬 경로, 현장 사진, 운영 데이터와 비공개 원본 저장소 포함 금지
- 시험 데이터와 시험 미디어에 합성 또는 공개 가능한 자료만 사용
- 사용자 비밀번호와 장기 인증 토큰의 브라우저 저장소 보관 금지
- 외부 입력을 Zod 스키마로 검증하고 유효하지 않은 데이터의 화면 전달 금지
- AI 작성, 생성 도구 및 `Co-Authored-By`를 나타내는 메타데이터 추가 금지
